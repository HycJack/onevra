# Changelog

User-facing updates for Onevra library consumers. No version has been published yet.

## [Unreleased]

- Use themed common controls from the `components` package (`github.com/oneo-me/onevra/components`), alongside MyGo's `ui` without import aliases.

- Use 1,866 Lucide icons directly with MyGo through `icons/lucide`, with named accessors, first-use parsing and inherited text colors. Preview representative icons at multiple sizes in the gallery.

- Create a native Shell through `shell.NewShell` with a default window size and matching minimum size, independently overridable by applications, and system window controls on macOS/Linux and rounded, localizable toolbar-style minimize, maximize/restore and close buttons on Windows and a full-height left sidebar with a Lucide toggle. The sidebar reveals beneath the main content without resizing the window and keeps its content width during animations. An overlay separator leaves no gap when collapsed; drag it or use arrow keys when focused to resize the sidebar within configurable minimum and maximum widths, without a proportional window-width cap; the resize handle stays within the window and extends through the titlebar to the top edge. Set a default width and restore it by double-clicking the separator. Read and restore the chosen width with `LeftWidth` and `SetLeftWidth` for application-owned persistence, without changing that default. Animations respect Reduced Motion. On macOS, the sidebar exposes the window's blurred background up to the top edge, while main content remains opaque. The toggle keeps clearance from traffic lights. Sidebar, main content and replacement pages extend behind a transparent floating header; use `shell.HeaderHeight(c)` to inset controls while allowing application backgrounds to cover the titlebar area. Dark sidebars use a blue-gray tint, translucent over macOS blur and opaque on Windows/Linux; Windows also distinguishes navigation with a contrasting surface in light mode.
- Add icon-only toolbar actions through `shell.IconButton` with accessible labels, tooltips and translucent text-color hover/press feedback. Place application actions in Shell's fixed left bottom toolbar, and supply a title, breadcrumbs or actions in the leading main-content titlebar area.
- Replace the entire sidebar-and-content page with application content such as settings, then restore the previous sidebar state.
- Try Shell in the standalone gallery, including light/dark appearances, sidebar controls and a replacement settings page.
- Use Onevra's built-in light and dark themes, applied through MyGo's theme mechanism so all MyGo widgets keep working. `ShellOptions.Appearance` selects `theme.Auto` (the default, follows the system appearance), `theme.Light` or `theme.Dark`. The palettes follow the Light and Shadow (light-shadow) design style from oneo-me/desgin-styles: a warm white light mode and a brighter blue-gray dark mode with layered surfaces and translucent text-colored scrollbars visible against both palettes; preview both in the gallery with `-theme light` or `-theme dark`.
